### ⚔️ Featured: [Sekiro Boss Practice Analytics](https://github.com/CanYouTeachMeHowToCode/Sekiro-boss-practice-analytics)

A full-stack app that tracks *Sekiro* boss attempts and shows which moves keep killing you.

- **Product:** React + TypeScript frontend, FastAPI + SQLAlchemy + PostgreSQL backend, accounts with server-side sessions, per-user analytics, English / 中文 interface, Docker Compose and four required CI jobs
- **Combat ground truth:** Genichiro's moveset rebuilt from the game's battle AI, animation data and dev-menu recordings instead of wiki lists: 63 moves from 45 AI chains, with every one of the 353 animation entries reviewed
- **Now:** reading gameplay recordings automatically. The prototype detects when the player takes damage or has their posture broken and names the boss move behind each failure. On recordings it was never tuned on, it ranked the right move first for 36 of 41 failures; validation on more recordings is under way
